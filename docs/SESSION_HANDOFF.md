## 3. Credential handling — standing rule, restated

Never type real credentials — passwords, API keys, trading account details — into chat with Claude, regardless of whether the account is real-money or demo. Once typed, treat it as exposed. Type real values directly into `.env` files or the app's own linking flow, never through a conversational interface. This has applied consistently to the MetaQuotes-Demo account, the OpenAI/Anthropic API keys, and now the WelTrade account — same rule, no exceptions for "it's just a demo."

## 4. What a resuming session (human or Claude) should do first

1. Read this file in full.
2. Read `CHANGELOG.md`'s most recent entries — trust them over re-deriving state from scratch.
3. Check whether E.8 has run yet (search recent CHANGELOG entries for `E8` / `OPTION2` / market-hours references).
4. Check Module 3's real observed cost via the usage script before assuming the soft-launch period is over.
5. Confirm nothing in the "hard stops" list above got quietly crossed while unsupervised — specifically check `git log` for any commit touching `bot-runtime.js` or a new `crypto-bot-runtime.js` file. If either exists, stop and review it carefully before trusting anything built on top of it.
6. Only then resume forward work.
